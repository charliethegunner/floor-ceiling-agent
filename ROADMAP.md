```
           ┌──────────────────────────────────────────────────┐
           │ 1. REVERSE SMT / TASK GENERATOR                  │
           │ Synthesizes novel edge cases & stress tests      │
           └────────────────────────┬─────────────────────────┘

           ┌──────────────────────────────────────────────────┐
           │ 2. META-EVOLVER & PROMPT MUTATION                │
           │ Mutates candidate logic & expands search paths   │
           └────────────────────────┬─────────────────────────┘
                                     │
                                     ▼
           ┌──────────────────────────────────────────────────┐
           │ 3. MULTI-ENGINE VERIFICATION FLOOR               │
           │ 100% Math Proof: Z3, Lean 4, or AST Checkers     │
           │ Filters out unsafe code and false steps          │
           └────────────────────────┬─────────────────────────┘
                                     │
                                     ▼
           ┌──────────────────────────────────────────────────┐
           │ 4. LAYER 5 GOVERNING META-KERNEL                 │
           │ TTL Garbage Collection: Prunes obsolete AST rules│
           │ Curriculum Gating: Keeps execution bounded       │
           └──────────────────────────────────────────────────┘
```

- **Synthetic Edge-Case Synthesis (Reverse Generator):** Runs SMT constraints in reverse to generate boundary-condition test cases automatically.
- **Zero-Latency AST Rule Compilation:** Compiles verified logic fixes directly into 0ms AST Micro-Fix Floor rules, bypassing the LLM on recurring error patterns.
- **Mathematical Selection Pressure:** Eliminates semantic prompt degradation by killing any candidate mutation that fails Layer 1 verification.
- **TTL Garbage Collection & Curriculum Gating:** Uses Time-To-Live (TTL) decay to purge stale micro-rules and maintain bounded latency profiles.
